## 平台下載

正式版完整套件發布後，可由 [GitHub Releases](https://github.com/Rex-Taiphoon/Taiphoon_Agent/releases) 取得。
支援 Windows AMD64、macOS AMD64／ARM64 與 Linux AMD64／ARM64；樹莓派選擇 Linux ARM64。

## 使用方式

- 先安裝 Docker Engine 與 Compose plugin，或啟動 Docker Desktop 的 Linux 容器。
- 解壓符合平台的完整套件後，執行 `taiphoon_agent`；首次啟動會引導設定。
- `deploy` 用於單機部署、`dev` 用於容器內開發、`sim` 用於 1～4 組 PX4＋Agent 模擬。
- 詳細設定見 [套件操作說明](../../Tools/agent_launcher/PACKAGE-README.md)。
