## 使用方式

- Ubuntu 22.04 安裝 Docker Engine 與 Compose plugin；Windows／macOS 安裝並啟動 Docker Desktop（Linux containers）。
- 下載符合 CPU 架構的完整套件並解壓縮；樹莓派選 `linux-arm64`，Apple Silicon 選 `macos-arm64`。
- Windows 執行 `./taiphoon_agent.exe start`；macOS／Linux 執行 `./taiphoon_agent start`。
- 首次啟動會引導設定、自動校驗並載入內附映像；後續沿用保存設定。啟動後由操作者下達 Arm 與起飛命令。
- 此版 Docker Desktop 的 `deploy`／`dev` 使用 host networking，需在 Desktop 4.34 以上啟用 **Enable host networking**；詳細步驟見套件內的 `README.md`。

## 主要變更

- 新增 Windows、macOS 與 Ubuntu AMD64／ARM64 的五種完整平台套件，內含啟動器與預編譯 Agent 映像。
- 新增 `deploy`、`dev`、`sim` 三種模式，分別用於單機部署、容器內開發與 PX4 模擬。
- 新增互動設定與保存功能，首次設定後可直接啟動。
- 新增 `start`、`stop`、`restart`、`status`、`logs` 與 `config` 指令，集中管理 Agent 容器。
- 新增跨平台 CI，通過編譯、Docker 內測試與套件檢查後自動發布。

## 驗證與限制

- CI：AMD64／ARM64 各 328 個 ROS2 測試與三組 CTest 通過；Windows／macOS 啟動器編譯通過；五個平台套件已上傳。
- 待驗收：樹莓派與 macOS 實機、Wi-Fi／外部 GCS 連線及現場飛行；macOS 套件尚未公證。
- ARM64 的 PX4 模擬需要 Docker 支援 AMD64 CPU 模擬。
